#### 1: Hai sai lầm trong tư duy của bạn Nam về việc dùng FILE WORD cho lưu trữ mã nguồn là:

- Sai lầm thứ nhất của bạn Nam là: Bạn Nam cho rằng dùng Microsoft Word tiện lợi hơn Github vì trên Microsoft Word có những thanh công cự mà trên Githob không có
- Sai lầm thứ hai của bạn Nam là: Bạn Nam cho rằng Markdown chỉ là văn bản thô nhìn không chuyên nghiệp

#### 2: Markdown an toàn và nhẹ hơn Microsoft Wold là:
- Nhẹ hơn là vì: FILE WORD là một tệp gồm nhiều file nên chiếm khá nhiều dung lượng bộ nhớ còn MARKDOWN là một tệp văn bản thô nên dung lượng sẽ nhẹ hơn

- An toàn hơn là vì: FILE WORD là khi bạn bị lỗi dù chỉ là một lỗi nhỏ trong quá trình tải file lên thì sẻ khiến cho toàn bộ file bị hỏng, không thể mở được. Còn MARKDOWN thì khi gặp sự cố ở mộ đoạn nào đó thì phần nội dung còn lại trong file vẫn sẻ đọc dược và khôi phục bình thường
